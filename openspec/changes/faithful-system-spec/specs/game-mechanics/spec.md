## Game Mechanics Specification (skeleton)

### Overview

This spec will capture deterministic behavior for: map generation, ship movement, combat resolution, economy, research, scoring, turn resolution.

### Sections

- Map generation: algorithm, seed, parameters, expected outputs
- Ship types: stats, costs, special abilities
- Movement & pathing: move points, fuel, gates
- Combat: resolution algorithm, phases, modifiers
- Economy & production: resource generation, build queues
- Turns & scheduling: when updates run, conflict resolution

### Example Scenario format

- **Requirement:** <Name>
- **Scenario:** <Name>
  - **WHEN** <trigger>
  - **THEN** <expected outcome>
