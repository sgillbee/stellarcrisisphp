# Table: `scouting_reports`

Source DDL: [sc.sql](sc.sql#L321-L344)

## Purpose

Persists scouting results captured by players: system owner, visible resources, and ships observed at the time of the scout. Used to show historical scouting data and to populate scouting UI.

## Columns

- `id` int(11) NOT NULL AUTO_INCREMENT — PK.
- `game_id` int(11) NOT NULL DEFAULT '0' — FK to `games.id`.
- `player_id` int(11) NOT NULL DEFAULT '0' — Scout author.
- `system_coordinates` varchar(11) NOT NULL DEFAULT '' — "x,y".
- `owner` varchar(20) NOT NULL DEFAULT '' — Owner seen at time of scout.
- `population` int(11) NOT NULL DEFAULT '0'
- `agriculture` int(11) NOT NULL DEFAULT '0'
- `mineral` int(11) NOT NULL DEFAULT '0'
- `ships_seen` text NOT NULL — Serialized list or summary of ships observed.
- `scouted_at` int(11) NOT NULL DEFAULT '0'

## Indexes

- KEY `game_system` (`game_id`,`system_coordinates`)

## Application mappings

- Generated by `update.php` and `update/moveship.php` when scouting/exploring actions discover new data.
- Displayed by `game/scouting.php` and included in player history/messages.
